AI chat

Claude Haiku writes short chat replies when someone talks to a bot that has "AI chat" on (turn it on under Default behaviour or in a bot's Settings). Bedrock uses this server's AWS access (the EC2 instance role), so no key is needed: just pick the region where Claude Haiku is enabled. Each reply costs a tiny amount; "AI replies per hour" caps it per bot.

Default behaviour

Used by every bot, unless that bot has its own value in its Settings tab.
Owners can type in game chat: !come !follow !stay !guard !roam !idle !goto <place> !here <name> !status !help
